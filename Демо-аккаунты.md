# Демо-аккаунты VoltPlan

Аккаунты и данные уже созданы в папках «Этап 3» и «Этап 3.1» (каталог
`site_data`). Запуск: «Запуск.bat» в папке этапа → откроется
<http://127.0.0.1:8000>. При запуске в окне написано, подключён ли консультант.

Пароль у всех аккаунтов один — `VoltPlan2026`; он же указан в каждой строке
таблиц. Логин — почта.

## Главный администратор

| Кто | Логин (почта) | Пароль | Тариф | Роль |
|---|---|---|---|---|
| Главный администратор | `admin@example.by` | `VoltPlan2026` | «Максимум» без срока | первый администратор сайта |

Отдельной роли «главный администратор» в программе нет: все администраторы
равны. Главный — тот, кто стал администратором первым, командой из README
(`python -m voltplan --make-admin admin@example.by`), а уже он через раздел
«Администрирование» назначил Ирину администратором, выдал себе «Максимум» без
срока, выдал тарифы Сергею и Li Wei, задал цену энергии и разослал всем
уведомление о плановых работах. Всё это видно в «Журнале действий». Своих
проектов и переписки у него нет — он только управляет сайтом.

## Порядок показа (примерно 10 минут)

1. **Гость:** главная, «Тарифы» (подбор по вопросам), «Состояние сервиса».
2. **Ирина:** кабинет (тариф, проекты, уведомления, платежи, свои марки) →
   «Каменка» в редакторе → «Расчёт» (F7) → «Итоги» → меню «Расчёт»:
   «Сравнение вариантов проекта» (лучший — «Замена ТП на ТМ-250»: у всех трёх
   пропускная способность недостаточна, а у этого выше наименьшее напряжение), «Сценарии расчёта» →
   «Рассчитать все», эпюра, годовые потери, отчёт DOCX.
3. **Совместная работа (Ирина):** команды и роли, чат команды с файлом,
   личная переписка с Павлом (скачать .cir и .xlsx).
4. **Павел** (второй браузер): открыть «Гатское» как редактор, изменить и
   сохранить; написать Ирине — у неё появится уведомление.
5. **Олег:** открыть «Подозерье (общий)» — «Только просмотр», посчитать можно,
   сохранить нельзя; попробовать создать третий проект — отказ «Демо»;
   принять приглашение Павла в друзья.
6. **Администрирование (главный администратор `admin@example.by`):** обзор
   по тарифам, пользователи (сменить тариф Сергею, выдать или снять права
   администратора — снять их с самого себя нельзя), журнал действий,
   справочник нагрузок, рассылка.
7. **Языки:** переключатель RU · EN · 中文 в шапке или вход под Li Wei.
8. **Оплата:** «Тарифы» → оплатить; карта `4111 1111 1111 1111`, срок любой в
   будущем, CVV `123` — успех; `4000 0000 0000 0002` — отказ банка.
9. **Консультант:** кнопка «Консультант» — например, «Как сравнить два
   варианта?».

## Консультант и ключ

Ключ доступа хранится в переменной окружения Windows `VOLTPLAN_CONSULTANT_KEY`
(уровень пользователя), а не в папках проекта: любую папку этапа можно
передавать — ключа в ней нет. Программа при запуске сама берёт ключ из этой
переменной и пишет в окне «Консультант подключён: ключ взят из переменной
окружения VOLTPLAN_CONSULTANT_KEY». На другом компьютере без этой переменной
сайт работает полностью, только консультант отвечает, что недоступен.

Программа читает переменную прямо из настроек Windows при каждом запуске,
поэтому ключ подхватывается всегда — и «Запуск.bat», и командой из README, даже
в окне, открытом до записи переменной. Проверено на этом компьютере.

### Если на компьютере переменной нет

Если в окне написано «Консультант не подключён», запишите ключ в переменную
окружения Windows одним из способов ниже. Ключ нигде в папке проекта хранить
не нужно, поэтому папку можно передавать другим.

**Через окно Windows (один раз, сохраняется для этого пользователя):**

1. Нажмите Win+R, введите `rundll32 sysdm.cpl,EditEnvironmentVariables` и
   нажмите Enter. Или: Пуск → начните вводить «переменные среды» → «Изменение
   переменных среды текущего пользователя».
2. В верхнем списке «Переменные среды пользователя» нажмите «Создать…».
3. Имя переменной — `VOLTPLAN_CONSULTANT_KEY`, значение — ключ доступа
   целиком, без пробелов и кавычек. Нажмите «ОК» в обоих окнах.
4. Закройте окно «Запуск.bat», если оно открыто, и запустите его снова.

**Командой (то же самое).** В окне «Командная строка»:

```
setx VOLTPLAN_CONSULTANT_KEY "ваш-ключ"
```

или в PowerShell:

```
[Environment]::SetEnvironmentVariable('VOLTPLAN_CONSULTANT_KEY', 'ваш-ключ', 'User')
```

Программа при каждом запуске читает переменную прямо из настроек Windows,
поэтому достаточно закрыть окно «Запуск.bat» (если оно открыто) и запустить его
снова — перезагружать компьютер, выходить из Windows или открывать новое окно
командной строки не нужно. Так же подхватывается переменная, записанная для всех
пользователей (в нижнем списке «Системные переменные»).

**Только на один запуск** (ничего не сохраняется) — в командной строке, в папке
этапа:

```
set VOLTPLAN_CONSULTANT_KEY=ваш-ключ
python -m voltplan --open
```

В macOS и Linux: `export VOLTPLAN_CONSULTANT_KEY=ваш-ключ` перед запуском.

**Проверка.** При запуске в окне сервера появляется строка «Консультант
подключён: ключ взят из переменной VOLTPLAN_CONSULTANT_KEY, записанной в Windows»
(или «…из переменной окружения…», если ключ задан в самом окне), а на странице
«Состояние сервиса» у консультанта — «Работает».

**Убрать ключ.** В том же окне переменных среды выделите
`VOLTPLAN_CONSULTANT_KEY` и нажмите «Удалить» (или командой
`reg delete HKCU\Environment /v VOLTPLAN_CONSULTANT_KEY /f`).

Ключ можно положить и в файл `site_data/consultant.key`, но тогда он лежит в
папке проекта — такую папку передавать нельзя.

## Как вернуть демо-данные в исходный вид

Удалите каталог `site_data` в папке этапа и выполните:

```
python "E:\claude-работа\Итог-работа\инструменты\демо-наполнение.py" "<папка этапа>"
```
