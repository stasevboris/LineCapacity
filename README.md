# VoltPlan

Веб-приложение для построения схем воздушных электрических сетей 0,4 кВ,
расчёта их режима и обмена схемами с программой LineCapacity в формате `.cir`.

Курсовой проект, кафедра «Информационные технологии», ГГТУ им. П. О. Сухого.

| Рылушкин Богдан Александрович | ИТП-41 | Программный продукт для построения модели электрической сети на холсте и моделирования её режима при разных сезонных нагрузках |
| Стасев Борис Васильевич | ИТП-41 | Программный продукт для моделирования режимов электрической сети по нескольким сценариям и обмена схемами во внешнем формате |

## Состояние: этап 3 — полный продукт

К редактору и расчёту этапов 1–2 добавлены сайт с учётными записями, проекты
на сервере, совместная работа, функции меню «Расчёт» LineCapacity, настройки
моделирования и сценарии, варианты схемы и их сравнение, тарифы с оплатой,
администрирование, три языка интерфейса и консультант. Всё, что было в
этапах 1 и 2, работает внутри проекта без изменений.

### Что умеет программа

- **Холст SVG в браузере.** Шины трансформатора, отходящие линии, опоры,
  пролёты, ответвления к линиям и к потребителям, потребители (цвет — по
  фазе), надписи и длины ЛЭП, свободные точки присоединения. Масштаб колесом
  мыши, перемещение полотна перетаскиванием, «Показать всю схему».
- **Построение по правилам LineCapacity.** Щелчок по синей точке открывает
  меню разрешённых действий: отходящая от ТП линия, пролёт между опорами,
  ответвление к другой линии (с признаком «Отпайка к одиночной опоре»),
  ответвление к потребителю, промежуточная опора, потребитель. Геометрия
  вычисляется на сервере теми же правилами, что в LineCapacity: одинаковые
  действия в обеих программах дают один и тот же файл. Правила и немногие
  отличия описаны в документе [«Построение схемы»](docs/06-Построение-схемы.md).
- **Параметры объектов.** Трансформатор (Sн, Pхх, Pкз, Uвн, Uнн, Uк, ПБВ),
  ЛЭП (марка, длина, фазность, фаза, погонные сопротивления), опора (надпись,
  число ответвлений), потребитель (дополнительные данные, адрес, типовые или
  индивидуальные параметры электропотребления). Окна заполняются так же, как
  в LineCapacity, числа показываются полностью. Окно ЛЭП показывает, как понята
  марка провода: материал, изоляция, число жил, сечение.
- **Справочник марок** из штатных баз LineCapacity: 75 трансформаторов и
  4899 марок проводов и кабелей с поиском.
- **Изменение схемы:** правка параметров, добавление ответвления к опоре со
  сдвигом части схемы, удаление по правилам LineCapacity, отмена действий
  по тем же шагам, что в LineCapacity.
- **Обмен файлами `.cir`:** открытие файлов LineCapacity и сохранение схемы.
  Нетронутый файл сохраняется байт-в-байт.
- **Расчёт режима** собственным расчётным ядром (пакет `linecapacity`):
  узловые уравнения трёхфазной четырёхпроводной сети, типовые и
  индивидуальные нагрузки, тепловой расчёт проводов и трансформатора.
  Одна и та же схема даёт те же числа, что в LineCapacity. Кнопка
  «Расчёт» (F7) открывает окно вида расчёта: летний период, зимний или оба,
  режим минимальных нагрузок.
- **Результаты на схеме**, как в LineCapacity:
  - напряжения у потребителей, красные ниже 198 В и выше 242 В;
  - температуры проводов, провод с наибольшей температурой выделен;
  - потребитель с наименьшим напряжением залит красным, рамка — цвета фазы;
  - напряжения на шинах ТП, суммарные мощности, температуры трансформатора.

  Переключатель «Лето / Зима / Мин. нагрузки». Любое изменение схемы убирает
  результаты с холста.
- **«Основные результаты расчётов»** — тот же текст, что в окне LineCapacity,
  с заключением о пропускной способности сети. Если наибольшее или наименьшее
  значение физически одинаково у нескольких объектов, может быть назван другой
  из них — число то же (см. «Расчётное ядро»). Окно открывается само, если
  потребителей два и больше. Кнопка «Итоги» показывает отчёт последнего
  расчёта по тому же правилу, что в LineCapacity.
- **Результаты в свойствах объекта**: токи по проводам и температура ЛЭП,
  напряжения и мощности потребителя, данные трансформатора — теми же строками,
  что в окнах LineCapacity; у трансформатора — графики коэффициента загрузки
  и температур обмоток и масла за сутки, по вкладкам «Летний период» и
  «Зимний период».
- **Единая структура схемы** (JSON) для клиента и сервера.

### Этап 3: сайт и совместная работа

- **Сайт:** главная страница с объёмной сценой сети, «Возможности»,
  «О продукте», «Вопросы», «Тарифы» (подбор тарифа по шести вопросам и
  сравнительная таблица), «Состояние сервиса», регистрация и вход. На
  страницах — анимированные сцены: эпюра напряжения за сутки, построение схемы
  по шагам редактора, пределы тарифов, путь действия от окна объекта до
  расчёта. Редактор, личный кабинет, «Совместная работа», оплата и
  администрирование — только после входа; без входа любой закрытый маршрут API
  отвечает `401`.
- **Учётные записи:** две раздельные базы SQLite — `credentials.db` (почта,
  соль и хэш пароля PBKDF2-HMAC-SHA256) и `voltplan.db` (всё остальное);
  сеанс — подписанный токен в cookie HttpOnly на 7 дней; после пяти неудачных
  попыток входа — пауза 5 минут; смена пароля завершает другие сеансы.
- **Проекты:** схема сохраняется в проект (Ctrl+S) и открывается снова в том же
  виде; переименование, архив, удаление. У проекта есть варианты схемы
  («+ Вариант» сохраняет текущую схему новым вариантом).
- **Совместная работа:** приглашения в друзья и в команды по почте; команды с
  ролями «владелец», «редактор», «читатель»; проект, открытый команде,
  читатель только смотрит и считает, редактор ещё и сохраняет. Переписка
  лично и в команде с передачей файлов до 5 МБ (кроме исполняемых);
  уведомления со счётчиком в шапке. Команды, приглашения, друзья и переписка
  собраны на странице «Совместная работа» (`/collab`); проекты, уведомления,
  тариф и платежи, свои марки и учётная запись — в личном кабинете
  (`/account`).

### Этап 3: моделирование

- **Меню «Расчёт»** (стрелка у кнопки «Расчёт»), как в LineCapacity:
  присвоить всем потребителям типовые (F6) или индивидуальные значения
  нагрузки; распределение нагрузок по показаниям балансного прибора; импорт
  получасовых нагрузок потребителей из файла Excel системы учёта; настройки
  расчёта. В окне потребителя после расчёта по двум периодам — «Рассчитать
  допустимую мощность потребителя» по потерям напряжения и по перегрузке
  трансформатора.
- **Справочник типовых нагрузок** (правит администратор): нагрузки лета, зимы
  и минимального режима бытовых потребителей без КИЭ и с КИЭ и освещения,
  cos φ, утяжеление, годовое потребление, температуры воздуха, допустимые
  напряжения и потери, суточные графики по получасам.
- **Настройки моделирования проекта** — на основе справочника; изменённые
  значения отмечены. **Сценарии** — именованные наборы настроек, период и
  режим; расчёт одного или всех со сводной таблицей.
- **Сравнение вариантов** проекта в сводной таблице: заключение, качество
  напряжения по ГОСТ 32144-2013, наименьшее напряжение, потери, температура
  провода, загрузка и износ трансформатора; лучший вариант и лучшие значения
  выделены.
- **Свои марки** ЛЭП и трансформаторов в справочнике редактора.
- **Эпюра напряжения** вдоль линии до выбранного потребителя, **годовые
  потери энергии** и их стоимость, **отчёт в формате DOCX**.

### Этап 3: тарифы, администрирование, языки, консультант

- **Тарифы:** «Демо» — бесплатно (2 проекта, схемы до 40 опор и
  40 потребителей), «Профессионал» — $19 за 30 дней (свои марки, отчёт DOCX,
  50 проектов), «Максимум» — $39 (эпюра, годовые потери, создание команд).
- **Оплата:** демонстрационная форма карты или тестовая среда bePaid;
  реальные деньги не списываются; история платежей в кабинете.
- **Администрирование** (`/admin`): обзор (пользователи по тарифам,
  регистрации за 14 дней), пользователи, тариф и срок, права
  администратора; платежи; журнал действий; рассылка уведомлений;
  справочник типовых нагрузок с суточными графиками; стоимость электроэнергии.
- **Языки:** русский, английский, китайский — переключатель RU · EN · 中文 в
  шапке, выбор сохраняется в профиле.
- **Консультант** — кнопка в правом нижнем углу страниц сайта и в шапке
  редактора; отвечает на вопросы о работе с VoltPlan после входа.
- **Состояние сервиса** (`/status`) опрашивает `GET /api/health` каждые
  10 секунд.
- Светлая и тёмная тема.

## Запуск

Нужен Python 3.11 или новее.

```
pip install -e .[test]
python -m voltplan --open
```

Или «Запуск.bat». Сервер работает на <http://127.0.0.1:8000>, документация
API — <http://127.0.0.1:8000/api/docs>. Данные сайта хранятся в каталоге
`site_data` (переменная `VOLTPLAN_DATA`).

Первый администратор: зарегистрируйтесь на сайте и выполните
`python -m voltplan --make-admin ваша@почта`.

Для оплаты через bePaid по умолчанию используется открытый тестовый магазин
bePaid; свой — переменные `VOLTPLAN_BEPAID_SHOP`, `VOLTPLAN_BEPAID_KEY`.

### Консультант: ключ доступа

Консультанту нужен ключ доступа. При запуске программа сама ищет его в
переменной `VOLTPLAN_CONSULTANT_KEY` — сначала в окне, из которого запущена,
затем в настройках Windows (переменные пользователя и системные), затем в файле
`site_data/consultant.key` — и пишет в окне сервера, подключён ли консультант и
откуда взят ключ (сам ключ не выводится). Без ключа всё остальное работает, а
консультант отвечает, что недоступен.

Если в окне написано «Консультант не подключён», запишите ключ в переменную
окружения Windows одним из способов ниже. Ключ нигде в папке проекта хранить
не нужно, поэтому папку можно передавать другим.

**Через окно Windows (один раз, сохраняется для этого пользователя):**

1. Нажмите Win+R, введите `rundll32 sysdm.cpl,EditEnvironmentVariables` и
   нажмите Enter. Или: Пуск → начните вводить «переменные среды» → «Изменение
   переменных среды текущего пользователя».
2. В верхнем списке «Переменные среды пользователя» нажмите «Создать…».
3. Имя переменной — `VOLTPLAN_CONSULTANT_KEY`, значение — ключ доступа
   целиком, без пробелов и кавычек. Нажмите «ОК» в обоих окнах.
4. Закройте окно «Запуск.bat», если оно открыто, и запустите его снова.

**Командой (то же самое).** В окне «Командная строка»:

```
setx VOLTPLAN_CONSULTANT_KEY "ваш-ключ"
```

или в PowerShell:

```
[Environment]::SetEnvironmentVariable('VOLTPLAN_CONSULTANT_KEY', 'ваш-ключ', 'User')
```

Программа при каждом запуске читает переменную прямо из настроек Windows,
поэтому достаточно закрыть окно «Запуск.bat» (если оно открыто) и запустить его
снова — перезагружать компьютер, выходить из Windows или открывать новое окно
командной строки не нужно. Так же подхватывается переменная, записанная для всех
пользователей (в нижнем списке «Системные переменные»).

**Только на один запуск** (ничего не сохраняется) — в командной строке, в папке
этапа:

```
set VOLTPLAN_CONSULTANT_KEY=ваш-ключ
python -m voltplan --open
```

В macOS и Linux: `export VOLTPLAN_CONSULTANT_KEY=ваш-ключ` перед запуском.

**Проверка.** При запуске в окне сервера появляется строка «Консультант
подключён: ключ взят из переменной VOLTPLAN_CONSULTANT_KEY, записанной в Windows»
(или «…из переменной окружения…», если ключ задан в самом окне), а на странице
«Состояние сервиса» у консультанта — «Работает».

**Убрать ключ.** В том же окне переменных среды выделите
`VOLTPLAN_CONSULTANT_KEY` и нажмите «Удалить» (или командой
`reg delete HKCU\Environment /v VOLTPLAN_CONSULTANT_KEY /f`).

Ключ можно положить и в файл `site_data/consultant.key`, но тогда он лежит в
папке проекта — такую папку передавать нельзя.

## Проверки

```
python -m pytest                                   модульные, API, стиль кода
python -m pytest tests/live -m live                в браузере Chrome
python -m pytest tests/linecapacity -m linecapacity   сверка с LineCapacity
```

Проверка стиля запускает ruff, если он установлен (`pip install -e .[test]`).

Для сверки с LineCapacity укажите путь к программе версии 1.27:
`set LINECAPACITY_EXE=C:\путь\LineCapacity1_27.exe`.

## Правила кода

- В коде нет комментариев и строк документации — ни в Python, ни в HTML, CSS,
  JavaScript, файлах настроек и командных файлах; это проверяет тест.
- Python 3.11+, PEP 8 (ruff), строки до 120 знаков, аннотации типов у
  публичных функций.
- Клиент — HTML, CSS и JavaScript (модули ES) без сборщика и сторонних
  библиотек.
- Каждый этап — самостоятельная программа; возможностей следующих этапов в
  нём нет.
