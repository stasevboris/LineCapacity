# Руководство пользователя

VoltPlan — веб-приложение для построения и расчёта схем воздушных и кабельных
сетей 0,4 кВ. Схемы сохраняются в проекты на сервере и обмениваются файлами
`.cir` с настольной программой LineCapacity в обе стороны.

## Запуск

Нужен Python 3.11 или новее.

```
pip install -e .[test]
python -m voltplan --open
```

Или «Запуск.bat». Браузер откроет <http://127.0.0.1:8000>. Данные сайта
хранятся в каталоге `site_data` рядом с программой (другой каталог —
переменная `VOLTPLAN_DATA`).

Первый администратор: зарегистрируйтесь на сайте и выполните
`python -m voltplan --make-admin ваша@почта`.

## Сайт и учётная запись

Без входа доступны главная страница, «Возможности», «О продукте», «Вопросы»,
«Тарифы» и «Состояние сервиса». Редактор, личный кабинет, «Совместная работа»
и оплата открываются только после входа: при попытке открыть их сайт
предложит войти и вернёт на нужную страницу.

1. «Начать бесплатно» → регистрация: имя, почта, пароль (не короче 8 знаков,
   полоса под полем показывает надёжность).
2. После регистрации или входа открывается редактор (или страница, на
   которую вы шли до входа). Новая учётная запись получает тариф «Демо».
3. «Выйти» в шапке завершает сеанс на этом устройстве; другие устройства
   остаются в системе. Смена пароля в кабинете завершает все остальные сеансы.

После пяти неверных паролей подряд вход для этой почты приостанавливается на
5 минут.

Переключатель RU · EN · 中文 в шапке меняет язык интерфейса; после входа выбор
сохраняется в профиле. Кнопка с солнцем и луной переключает светлую и тёмную
тему.

## Редактор

Кнопка «Редактор» в шапке. Вверху — панель кнопок, слева — холст со схемой,
справа — свойства выбранного объекта, внизу — строка состояния и масштаб.

### Новая схема

1. «Новая схема».
2. Выберите трансформатор из справочника, марку первой отходящей ЛЭП, опору.
3. На холсте появляются шины ТП, первая линия и опора с синими точками
   присоединения.

### Построение

Схема растёт от синих точек. Щелчок по точке (или Insert, «+» для выбранной
точки) открывает меню разрешённых в этом месте действий:

- отходящая от ТП ЛЭП;
- пролёт между опорами;
- промежуточная опора;
- ответвление к другой линии (флажок «Отпайка к одиночной опоре»);
- ответвление к потребителю;
- потребитель.

Набор действий и размещение объектов такие же, как в LineCapacity, поэтому
одинаковые действия в обеих программах дают один и тот же файл `.cir`.
Подробно правила описаны в документе «Построение схемы».

Марки проводов и трансформаторов выбираются кнопкой «Справочник…» в окне
объекта: 4899 марок проводов и кабелей и 75 трансформаторов с поиском. В
тарифах «Профессионал» и «Максимум» в справочнике есть и свои марки (их
добавляют в кабинете, раздел «Свои марки»).

### Изменение схемы

- Щелчок по объекту выделяет его и открывает свойства справа. Измените
  значения и нажмите «Применить».
- «Удалить» в свойствах или клавиша Delete удаляет объект по правилам
  LineCapacity (вместе с тем, что от него зависит).
- «Отменить» (Ctrl+Z) отменяет последнее действие.
- Колесо мыши — масштаб, перетаскивание пустого места — сдвиг полотна, F4 —
  показать всю схему. Escape закрывает открытое меню или окно.

### Файлы `.cir`

- «Открыть .cir» (Ctrl+O) открывает файл LineCapacity.
- «Сохранить .cir» сохраняет схему в файл, который открывается в
  LineCapacity в том же виде. Файл, открытый и не изменённый, сохраняется
  байт-в-байт.

## Расчёт

1. «Расчёт» (F7).
2. Выберите период: летний, зимний или оба; при необходимости — режим
   минимальных нагрузок.
3. «Запустить расчёт».

Если схема не может быть рассчитана (нет потребителей, ЛЭП нулевой длины,
марка без сечения и т. п.), появляется сообщение с причиной.

Результаты на схеме:

- напряжения у потребителей — красные ниже 198 В и выше 242 В;
- температуры проводов; провод с наибольшей температурой выделен;
- потребитель с наименьшим напряжением залит красным, рамка — цвета фазы;
- напряжения на шинах ТП, суммарные мощности, температуры трансформатора.

Переключатель «Лето / Зима / Мин. нагрузки» в строке состояния меняет
показанный режим. Любое изменение схемы убирает результаты с холста —
посчитайте заново.

Окно «Основные результаты расчётов» открывается само, если потребителей два и
больше; кнопка «Итоги» показывает его снова. В нём — заключение о
пропускной способности сети.

В свойствах объектов после расчёта видны результаты: токи и температура ЛЭП,
напряжения и мощности потребителя, данные трансформатора с графиками
коэффициента загрузки и температур обмоток и масла за сутки (вкладки
«Летний период» и «Зимний период»).

### Меню «Расчёт»

Стрелка ▾ рядом с кнопкой «Расчёт»:

| Пункт | Что делает |
|---|---|
| Запуск расчёта (F7) | окно вида расчёта |
| Основные результаты последнего расчёта | то же, что «Итоги» |
| Присвоить всем потребителям типовые значения нагрузки (F6) | все потребители получают типовую нагрузку по своему виду; заодно температуры воздуха для проводов возвращаются к значениям справочника |
| Присвоить всем потребителям индивидуальные значения нагрузки | все потребители переводятся на индивидуальную нагрузку |
| Распределение нагрузок по данным с балансного прибора | мощность, измеренная прибором на шинах, распределяется между потребителями; программа предлагает подходящий период расчёта |
| Импорт индивидуальных нагрузок из файла Excel | получасовые показания системы учёта; адрес прибора берётся из дополнительных данных потребителя («Адрес прибора АСКУЭ: 12345, …») |
| Настройки расчёта | значения проекта на основе справочника типовых нагрузок |
| Сценарии расчёта | именованные наборы настроек, периода и режима |
| Сравнение вариантов проекта | сводная таблица вариантов |
| Отчёт в формате DOCX | «Профессионал» и выше |
| Эпюра напряжения вдоль линии | «Максимум» |
| Годовые потери энергии и их стоимость | «Максимум» |

В свойствах потребителя после расчёта по двум периодам, если пропускная
способность достаточна, есть кнопка «Рассчитать допустимую мощность
потребителя».

### Настройки и сценарии

В окне «Настройки расчёта» значения, отличные от справочника, отмечены.
Кнопка «↺» у строки возвращает одно значение, «Вернуть все значения
справочника» — все. Значения проверяются: например, наименьшее допустимое
напряжение должно быть ниже номинального, а номинальное — ниже наибольшего.

Сценарий — именованный набор настроек, периода и режима; сценарии хранятся
в проекте. В окне «Сценарии расчёта»: «Добавить сценарий», «Изменить»,
«Удалить», «Рассчитать» у строки и «Рассчитать все» — результаты всех
сценариев сводятся в таблицу.

### Варианты и сравнение

У проекта может быть несколько вариантов схемы. Над холстом — список
вариантов, «+ Вариант» сохраняет текущую схему новым вариантом, рядом кнопки
переименования и удаления (основной вариант удалить нельзя).

«Сравнение вариантов проекта»: отметьте варианты и нажмите «Сравнить».
Таблица показывает заключение, качество напряжения по ГОСТ 32144-2013,
наименьшее напряжение, потери, температуру провода, загрузку и износ
трансформатора, годовые потери. Лучший вариант выбирается по порядку:

1. пропускная способность достаточна;
2. напряжение у всех потребителей в пределах ±10 % номинального;
3. выше наименьшее напряжение у потребителя;
4. ниже потери мощности.

Лучший вариант и лучшие значения столбцов выделены, правило выводится под
таблицей.

## Проекты

- «Сохранить в проект» (Ctrl+S): новая схема сохраняется в новый проект,
  открытый проект — в текущий вариант.
- «Проекты» открывает список проектов; проект открывается в том же виде, в
  каком был сохранён.
- В личном кабинете, раздел «Проекты»: создать, переименовать, убрать в архив,
  вернуть из архива, удалить, открыть команде («Команде…»).

Число проектов, вариантов и сценариев ограничено тарифом.

## Совместная работа

Страница «Совместная работа» (`/collab`).

- **Друзья.** Приглашение по почте; после принятия друг виден в списке и
  доступен в переписке.
- **Команды** (создаёт пользователь тарифа «Максимум»). Владелец приглашает
  участников по почте с ролью «редактор» или «читатель». Приглашённый
  принимает или отклоняет приглашение на той же странице.
- **Общие проекты.** Владелец открывает проект команде в кабинете кнопкой
  «Команде…». Редактор открывает, считает и сохраняет изменения; читатель
  только смотрит и считает — редактор показывает пометку «Только просмотр».
- **Переписка** лично и в команде, с файлами до 5 МБ. Исполняемые файлы не
  принимаются.

О приглашениях, сообщениях и платежах приходят уведомления; счётчик — в
шапке, список — в кабинете, раздел «Уведомления».

## Консультант

Кнопка консультанта — в правом нижнем углу страниц сайта и в шапке редактора.
Консультант отвечает после входа на вопросы о работе с VoltPlan на языке
вопроса. Не больше 30 вопросов в час на пользователя.

Консультанту нужен ключ доступа. При запуске программа сама ищет его в
переменной `VOLTPLAN_CONSULTANT_KEY` — в окне запуска, затем в настройках Windows
(переменные пользователя и системные), затем в файле `site_data/consultant.key` —
и пишет в окне сервера, подключён ли консультант и
откуда взят ключ. Без ключа он сообщает, что недоступен.

Если в окне написано «Консультант не подключён», запишите ключ в переменную
окружения Windows одним из способов ниже. Ключ нигде в папке проекта хранить
не нужно, поэтому папку можно передавать другим.

**Через окно Windows (один раз, сохраняется для этого пользователя):**

1. Нажмите Win+R, введите `rundll32 sysdm.cpl,EditEnvironmentVariables` и
   нажмите Enter. Или: Пуск → начните вводить «переменные среды» → «Изменение
   переменных среды текущего пользователя».
2. В верхнем списке «Переменные среды пользователя» нажмите «Создать…».
3. Имя переменной — `VOLTPLAN_CONSULTANT_KEY`, значение — ключ доступа
   целиком, без пробелов и кавычек. Нажмите «ОК» в обоих окнах.
4. Закройте окно «Запуск.bat», если оно открыто, и запустите его снова.

**Командой (то же самое).** В окне «Командная строка»:

```
setx VOLTPLAN_CONSULTANT_KEY "ваш-ключ"
```

или в PowerShell:

```
[Environment]::SetEnvironmentVariable('VOLTPLAN_CONSULTANT_KEY', 'ваш-ключ', 'User')
```

Программа при каждом запуске читает переменную прямо из настроек Windows,
поэтому достаточно закрыть окно «Запуск.bat» (если оно открыто) и запустить его
снова — перезагружать компьютер, выходить из Windows или открывать новое окно
командной строки не нужно. Так же подхватывается переменная, записанная для всех
пользователей (в нижнем списке «Системные переменные»).

**Только на один запуск** (ничего не сохраняется) — в командной строке, в папке
этапа:

```
set VOLTPLAN_CONSULTANT_KEY=ваш-ключ
python -m voltplan --open
```

В macOS и Linux: `export VOLTPLAN_CONSULTANT_KEY=ваш-ключ` перед запуском.

**Проверка.** При запуске в окне сервера появляется строка «Консультант
подключён: ключ взят из переменной VOLTPLAN_CONSULTANT_KEY, записанной в Windows»
(или «…из переменной окружения…», если ключ задан в самом окне), а на странице
«Состояние сервиса» у консультанта — «Работает».

**Убрать ключ.** В том же окне переменных среды выделите
`VOLTPLAN_CONSULTANT_KEY` и нажмите «Удалить» (или командой
`reg delete HKCU\Environment /v VOLTPLAN_CONSULTANT_KEY /f`).

Ключ можно положить и в файл `site_data/consultant.key`, но тогда он лежит в
папке проекта — такую папку передавать нельзя.
