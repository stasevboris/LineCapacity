# План этапа 3 — полный продукт

## Цель

Сделать из редактора и расчёта законченный продукт: работа ведётся в личных
проектах на сервере, одну сеть можно моделировать по нескольким сценариям,
варианты схемы сравниваются по результатам расчёта, доступ оплачивается по
тарифам. Всё, что было в этапах 1 и 2, работает внутри проекта без изменений;
сверка с LineCapacity остаётся и расширяется на функции меню «Расчёт».

## Что добавляется

### Пользователи, проекты, совместная работа

| Часть | Содержание |
|---|---|
| сайт | главная страница, регистрация, вход, выход, личный кабинет; редактор доступен только после входа |
| хранение | две раздельные базы SQLite в каталоге данных сервера: `credentials.db` — только почта, хэш и соль пароля (PBKDF2-HMAC-SHA256); `voltplan.db` — профили, проекты, команды, приглашения, друзья, сообщения, общие проекты, уведомления, сценарии, варианты, платежи, журнал действий |
| вход | подписанный ключом сервера токен в cookie (HttpOnly, SameSite); ограничение числа неудачных попыток входа |
| проекты | создать, сохранить, открыть, переименовать, убрать в архив и вернуть, удалить; схема хранится в единой JSON-структуре; «Сохранить .cir» работает, как прежде |
| доступ | владелец — всё; проект, открытый команде: «читатель» только просматривает и считает, «редактор» ещё и сохраняет; чужой проект без доступа не открывается (404), сохранение без права — 403 |
| совместная работа | приглашения в друзья и в команды по почте; команды с ролями «владелец», «редактор», «читатель»; переписка лично и в команде с передачей файлов (до 5 МБ, без исполняемых); уведомления с отметкой о прочтении и счётчиком в шапке |

### Настройки моделирования и сценарии

- Справочник типовых нагрузок (общий, правит администратор): все величины
  расчёта — нагрузки лета, зимы и минимального режима для бытовых
  потребителей без КИЭ и с КИЭ и для освещения, cos φ, утяжеление, годовое
  потребление типовых потребителей, температуры воздуха, допустимые
  напряжения и потери, суточные графики по получасам.
- Настройки моделирования проекта: сезонные наборы нагрузок на основе
  справочника с уточнением значений; изменённые значения видны.
- Сценарии: несколько именованных сценариев в проекте (набор нагрузок, период,
  режим минимальных нагрузок); расчёт одного или всех; сводная таблица
  результатов по сценариям.
- Функции меню «Расчёт» LineCapacity, со сверкой с программой:
  - присвоить всем потребителям типовые или индивидуальные значения нагрузки;
  - настройки расчёта;
  - допустимая мощность потребителя — по потерям напряжения и по перегрузке
    трансформатора;
  - импорт индивидуальных нагрузок из файла Excel в формате LineCapacity;
  - распределение нагрузок потребителей по показаниям балансного прибора.
- Свои марки ЛЭП и трансформаторов пользователя.

### Варианты и сравнение

- Варианты схемы в проекте: основной и альтернативные (создать из текущего,
  переименовать, открыть, удалить).
- Сравнение вариантов по выбранному сценарию: сводная таблица показателей —
  заключение, качество напряжения, наименьшее напряжение, потери мощности и
  напряжения, наибольшая температура провода, загрузка и износ трансформатора;
  лучший вариант и лучшие значения выделены.
- Качество напряжения у каждого потребителя по ГОСТ 32144-2013.
- Правило лучшего варианта, по порядку: пропускная способность достаточна;
  качество напряжения в норме; выше наименьшее напряжение у потребителя; ниже
  потери мощности.

### Тарифы, администрирование, языки, консультант

- Тарифы «Демо», «Профессионал», «Максимум» (цены в долларах США): пределы
  размера схемы, числа проектов и вариантов в сравнении; страница тарифов;
  отметка тарифа в шапке.
- Оплата: демонстрационная форма карты и песочница платёжного сервиса bePaid;
  история платежей; срок действия тарифа.
- «Профессионал»: свои марки, отчёт в формате DOCX. «Максимум»: эпюра
  напряжения вдоль линии, годовые потери энергии и их стоимость в отчёте и в
  сравнении, создание команд.
- Панель администратора: пользователи, тарифы, журнал действий, уведомления,
  справочник типовых нагрузок, стоимость электроэнергии.
- Интерфейс на русском, английском и китайском языках.
- Консультант на сайте: отвечает на вопросы о работе с программой.

## Порядок работ

1. Хранение, регистрация, вход, проекты, доступ.
2. Совместная работа.
3. Справочник типовых нагрузок, настройки моделирования, сценарии.
4. Функции меню «Расчёт» с расширением расчётного ядра (допустимая мощность,

5. Свои марки.
6. Варианты, качество напряжения, сравнение.
7. Тарифы и оплата.
8. Администрирование.
9. Языки интерфейса.
10. Консультант.
11. Документы: README, архитектура (маршруты, таблицы, модули), план
    тестирования, расчётное ядро.

## Проверки

- **Модульные:** хэш и проверка пароля, токен (подделка, истечение),
  раздельность баз, права по ролям, файлы в переписке, справочник нагрузок →
  настройки расчёта, сценарии, допустимая мощность, импорт Excel, балансный
  прибор, качество напряжения, правило лучшего варианта, пределы тарифов,
  платежи, полнота словарей трёх языков.
- **API:** любой маршрут проектов без входа — 401; чужое — 404; без права —
  403; сверх тарифа — отказ с понятным сообщением; маршруты администратора
  недоступны обычному пользователю.
- **В браузере, несколькими пользователями:** регистрация → проект →
  сохранение → выход → вход → открытие даёт ту же схему; команда и права;
  переписка с файлом; сценарии и сводная таблица; варианты и сравнение;
  оплата; администрирование; три языка; консультант.
- **Сверка с LineCapacity:** все проверки этапов 1 и 2; присвоение типовых и
  индивидуальных нагрузок, допустимая мощность, импорт из Excel, балансный
  прибор, изменённые настройки расчёта — результаты совпадают.
