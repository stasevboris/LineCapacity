## Проверки в браузере

- Расчёт образца «Каменка»: отчёт, подписи для лета, зимы и режима
  минимальных нагрузок совпадают с ответом сервера; красная отметка худшего
  потребителя с рамкой цвета фазы и выделение самой нагретой ЛЭП стоят на

  «Недостаточно потребителей в схеме!», с одним трёхфазным — отчёт.
- Открытие файла делает «Итоги» недоступными до расчёта.

  «Сечение фазного провода: не определено».
- Отказ в расчёте схемы без потребителей.
- В панели свойств никогда нет лишнего текста, в консоли браузера нет ошибок.

Каждая сверка заодно проверяет, что записанные данные совпадают с тем, что
LineCapacity выводит сейчас.

### Равные значения

Числа во всех отчётах и окнах совпадают с LineCapacity. В 6 из 18 образцов
отличается название самой нагретой ЛЭП или потребителя с наименьшим
напряжением: у нескольких объектов значение физически одинаково (пролёты
одной марки с одним током), и программы называют разные из них. Всего таких
подстановок 14, каждая записана с причиной; использованные в прогоне
подстановки лежат в `журналы/linecapacity/*-подстановки.txt`. Подробнее — в
документе «Расчётное ядро», раздел «Равные значения».

## Дефекты, найденные при тестировании и исправленные

| Что было | Как найдено | Исправление |
|---|---|---|
| числа с длинной целой частью выводились без записи с порядком (`212824000,00` вместо `2,12824E8`) | сверка окна трансформатора на малой мощности | правило вывода с порядком и `INF`, ограничения значений в ядре сняты |
| «Итоги» после схемы с одним потребителем показывали отчёт прежней схемы | сценарий в браузере и в LineCapacity | правило LineCapacity: отчёт хранится после каждого расчёта, кнопка — по числу ветвей напряжения |
| потребитель с наименьшим напряжением заливался цветом фазы | снимки обеих программ | красная заливка, рамка цвета фазы |
| схема без ЛЭП или с ЛЭП нулевой длины давала ответ 500 | искажённые запросы | отказ с понятным сообщением; затем добавлены отказы для потребителя или опоры вне ЛЭП, ЛЭП не с опоры, марки без сечения, cos φ ≤ 0 |
| схема на 299 опор считалась 38 с | синтетические крупные схемы | словари связности, разреженная матрица: 0,22 с |
| в окне трансформатора не было суточных графиков | сравнение окон | графики коэффициента загрузки и температур по вкладкам сезонов |
| число жил у марки из одного знака не совпадало | разбор марки | правило LineCapacity |
| при равных значениях названия объектов отличались, а проверки это скрывали допуском | построчное сравнение отчётов | подстановки записаны в данные проверок с причиной, отличие описано |
| заключение при кратковременной перегрузке и подписи на схеме не были защищены проверками | намеренная порча кода | записанные схемы с перегрузкой и нагревом СИП, сверка подписей и отметок с окнами LineCapacity |
| в панели свойств выводился текст «null» | снимок экрана | пустые части панели не выводятся, живые проверки это контролируют |
| при напряжениях не ниже 400 В потери напряжения считались по другой фазе | сверка схемы с Uнн = 1 кВ | правило выбора фазы как в LineCapacity |
| окно ЛЭП не показывало, как понята марка провода | сравнение окон | четыре строки разбора марки, как в LineCapacity |
| на ширине 1100 пикселей панель сезонов закрывала кнопку масштаба | снимок узкого окна | панель переносится и не заходит под кнопки |
| текст окна сообщения LineCapacity не читался при русской раскладке | прогон сверки | Ctrl+C нажимается кодом клавиши |

## Материалы

- `журналы/` — вывод трёх прогонов pytest и журнал сервера;
  `журналы/linecapacity/` — тексты «Основных результатов», снятые с
  LineCapacity, окна объектов и использованные подстановки.
- `запросы/` — 8 запросов к API: файл `.http` и настоящий ответ сервера в
  `.json` рядом: расчёт обоих периодов, лета без режима минимальных нагрузок,
  схемы с одним трёхфазным потребителем, отказы, ошибка вида расчёта, разбор
  марки провода. В ответах расчёта списки сокращены до трёх элементов.
- `скриншоты/` — снимки интерфейса VoltPlan (`интерфейс-*`) и окна
  LineCapacity после расчёта каждой сверяемой схемы (`linecapacity-*`).
- Схемы и записанные результаты LineCapacity — `tests/data/calc`.
