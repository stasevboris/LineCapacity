# Итоговая трассировка требований

Для каждого требования документа «Требования» указано, где оно выполнено и
какими проверками подтверждено. Наборы проверок: модульные и API
(`python -m pytest`), в браузере (`tests/live`, `-m live`), сверка с настоящей
LineCapacity 1.27 (`tests/linecapacity`, `-m linecapacity`). Итоги прогонов —
в «Отчёте о тестировании этапа 3».
