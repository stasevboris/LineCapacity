# Отчёт о тестировании этапа 3

Проверялась программа этапа 3: сайт с учётными записями, проекты на сервере,
совместная работа, функции меню «Расчёт» LineCapacity, настройки
моделирования и сценарии, варианты схемы и их сравнение, тарифы и оплата,
администрирование, три языка интерфейса, консультант — и то, что всё из
этапов 1 и 2 работает без изменений. Код этапа 3.1 совпадает с кодом
этапа 3; журналы — последнего полного прогона этапа 3.

## Проверки в браузере

13 сценариев сайта (`tests/live/test_site_ui.py`, несколько пользователей в
отдельных окнах браузера) и 37 сценариев редактора этапов 1–2
(`tests/live/test_editor_ui.py`).

- Регистрация с ошибкой пароля, вход после выхода, закрытые страницы ведут на
  вход и обратно.
- Сохранить проект — выйти — войти — открыть: та же схема.
- Команда: создание, приглашение по почте с ролью, принятие; проект открыт
  команде; читатель видит «Только просмотр», считает, но не сохраняет.
- Друзья: приглашение, переписка, файл скачивается тем же.
- Меню «Расчёт»: настройки (изменённое значение отмечено), допустимая
  мощность, балансный прибор предлагает период расчёта; импорт из Excel;
  сценарии со сводной таблицей.
- Сравнение вариантов: таблица, лучший вариант и лучшие значения выделены.
- Эпюра, годовые потери, отчёт DOCX в «Максимуме» и отказ в «Демо».
- Оплата демонстрационной картой: отказ банка и успех, тариф в шапке, история.
- Администратор меняет тариф пользователя и справочник нагрузок, обзор
  считает пользователей по тарифам.
- Английский и китайский: главная, редактор, меню «Расчёт», отчёт, свойства
  потребителя, ЛЭП и трансформатора после расчёта, имя основного варианта и
  окно переименования, окно сравнения, кабинет, «Совместная работа» — без
  русского текста, кроме данных пользователя из схемы.
- Все открытые страницы сайта на экране телефона без горизонтальной
  прокрутки.
- В консоли браузера нет ошибок ни в одном сценарии.

## Вид при увеличении

Все страницы сайта, кабинет, «Совместная работа» с перепиской, оплата, все
разделы администрирования и все окна редактора (меню «Расчёт», настройки,
сценарии, сравнение, эпюра, годовые потери, свойства объектов с результатами,
проекты, консультант, меню точки) сняты на демо-данных при масштабе браузера
100, 150, 200 и 300 % (экран 1920 × 1080), на русском, английском и китайском,
в светлой и тёмной теме — 420 состояний. Подборка — `скриншоты/увеличение-*`. Каждый снимок проверялся
автоматически (прокрутка вбок, обрезанный текст, элементы за краем окна,
пересечение кнопок и полей по видимой части) и просматривался. Редактор при
окне уже 900 пикселей (300 %) намеренно показывает просьбу развернуть окно.

## Дефекты, найденные при тестировании и исправленные

| Что было | Как найдено | Исправление |
|---|---|---|
| текст «0.75» с точкой в ячейке Excel читался как число | сверка импорта с LineCapacity | число — только с десятичной запятой, иначе 10⁻¹⁵ кВт без изменения cos φ |
| после неверного адреса в файле Excel чтение шло дальше | сверка импорта | строка обрабатывается с прежним адресом, затем чтение прекращается; сверяются все окна сообщений |
| адрес в дополнительных данных без запятой давал полупримененный импорт | сверка импорта | отказ «Импорт прерван…», схема не меняется; отличие описано в «Расчётном ядре» |
| возврат проекта из архива обходил предел тарифа | независимая проверка | предел проверяется и при возврате, создание — внутри транзакции |
| один счёт мог зачислиться дважды | независимая проверка | счёт и продление тарифа — в одной транзакции |
| младший тариф сокращал действующий старший | независимая проверка | младший не продаётся при старшем; старый счёт продлевает старший пропорционально цене; при переходе остаток младшего зачитывается; тариф без срока не продаётся повторно |
| выход не завершал сеанс: скопированная cookie продолжала работать | независимая проверка | выход отзывает токен, в токен добавлена случайная часть |
| `/app.html` и его варианты написания открывались без входа | независимая проверка | любое написание имени закрытой страницы ведёт на вход; путь, который нельзя открыть как файл, — `404` |
| исполняемые вложения проходили с точкой в конце имени | независимая проверка | имя очищается, список расширений расширен, отклоняется содержимое с сигнатурами исполняемых файлов |
| крайние значения настроек давали ошибку сервера | искажённые запросы | пределы величин и их соотношений, понятный отказ |
| пределы «Демо» не проверялись в функциях меню «Расчёт» | независимая проверка | предел размера схемы во всех функциях |
| результаты в свойствах объектов и часть подписей не переводились | живая проверка трёх языков | каждая строка — отдельный узел, шаблоны строк в словарях, сборщик строк находит строки из любого числа частей |
| годовые потери при наибольшей нагрузке ≤ 0 давали бессмысленные числа | искажённые настройки | отказ с пояснением, в сравнении — «—» |
| ошибки в правилах анализа не ловились проверками | намеренная порча кода | `test_analysis_rules.py` с ответами, посчитанными вручную |
| при 150–200 % ссылки шапки сайта не помещались, «Выйти» обрезалось; меню-«гамбургер» обрезалось самой шапкой и показывало гостю пункты для вошедших | осмотр при увеличении | «гамбургер» до 1300 пикселей, без обрезки, только свои пункты; живая проверка на экране телефона |
| при 1280–1700 пикселях кнопки варианта в шапке редактора уходили под переключатель языка | осмотр при увеличении (пересечение кнопок) | панель проекта переносится на вторую строку до 1700 пикселей |
| меню «Расчёт» выходило за край окна; меню точки пряталось под панелью сезонов; строки результатов в свойствах обрезались | осмотр при увеличении | меню сдвигается и прокручивается, меню точки выше панели, строки переносятся |
| имена участников команды сжимались до букв; таблица проектов кабинета и таблица сравнения не помещались | осмотр при увеличении | перенос кнопок участника, карточки проектов на узком окне, компактная таблица сравнения |

## Материалы

- `журналы/` — вывод трёх прогонов pytest и журнал сервера;
  `журналы/linecapacity/расчёт` — тексты «Основных результатов», снятые с
  LineCapacity, снимки окон и использованные подстановки;
  `журналы/linecapacity/меню` — файлы `.cir`, сохранённые LineCapacity после
  функций меню «Расчёт», и снимки окон.
- `запросы/` — 14 запросов к API: файл `.http` и настоящий ответ сервера в
  `.json` рядом: регистрация, неверный пароль, закрытый маршрут без входа,
  создание проекта, отказ в настройках, присвоение типовых нагрузок,
  сравнение вариантов, эпюра в «Демо» (`403`) и в «Максимуме», счёт, отказ
  банка (`402`), успешная оплата, младший тариф при старшем (`409`),
  состояние сервиса. В ответах списки сокращены до трёх элементов, схема в
  запросах после четвёртого заменена пометкой.
- `скриншоты/` — снимки интерфейса из прогона в браузере.
- Руководство пользователя — `docs/08-Руководство-пользователя.md`.
