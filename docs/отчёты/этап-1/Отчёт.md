## Проверки в браузере

Сервер запускается в тесте, браузер Chrome управляется через Playwright.

- Пустой редактор, окно новой схемы, новая схема.
- Все 10 сценариев из `tests/sequences.py` проходятся через интерфейс:
  щелчки по точкам, пункты меню, поля окон, панель свойств, кнопка «Отменить».
  Сохранённый из браузера файл совпадает байт-в-байт с файлом, который строит
  серверный движок по тем же действиям.
- Меню точки, свойства опоры, справочник марок, тёмная тема.
- Отказ в удалении опоры показывается сообщением, при открытии окна сообщение
  скрывается; отмена возвращает схему на шаг назад.
- Открытие трёх образцов: число ЛЭП, опор, потребителей и точек на холсте
  совпадает с файлом, сохранение возвращает тот же файл.
- Образец «Ботвиново»:
  - однофазный пролёт показан в свойствах однофазным (R 0,84, фаза L2);
  - мощность потребителя показана полностью: 0,180853658536585;
  - после правки двух надписей файл совпадает с ожидаемым байт-в-байт.
- Выбор фазности есть у любой ЛЭП, и в окне добавления, и в свойствах.
- При ширине окна меньше 900 пикселей показывается сообщение, горизонтальной
  прокрутки нет.
- В консоли браузера нет ошибок, кроме сетевых записей о намеренных отказах.

## Сверка с настоящей LineCapacity

Программа LineCapacity запускается и управляется из тестов: пункты меню,
щелчки по схеме, поля окон, «Сохранить как». Последовательности действий
задают только поля, видимые в окне, остальное берётся из заполнения окна —
как у пользователя.

| Сценарий | Что проверяет |
|---|---|
| базовая | отходящая ЛЭП, пролёт, ответвления к потребителям (одно- и трёхфазные), ответвление к линии |
| сложная | вторая отходящая со сдвигом вниз, отпайка к одиночной опоре, добавление ответвления к опоре со сдвигом вправо, удаление потребителя |
| правка | правка ТП, ЛЭП (смена фазности 3→1 и 1→3 с переносом на потребителя, длина), опоры, потребителя; добавления после правок со значениями по умолчанию |
| умолчания | все окна приняты без изменений |
| первая-лэп | новая ЛЭП другого вида повторяет первую ЛЭП схемы |
| отмена | отмена пролёта, опоры, потребителя; отмена после удаления и после добавления ответвления |
| отмена-отходящей | отмена отходящей ЛЭП, затем опора на свободном конце и новая отходящая |
| отмена-новой | отмена первой опоры новой схемы, затем достройка |
| удаление | удаление потребителя, ЛЭП, опоры со сдвигом нижней отходящей; новые объекты в освободившихся ячейках; щелчок по точке |
| свободные-концы | промежуточная опора и потребитель на свободном конце, щелчок по точке ответвления |

Кроме сценариев:

- надписи в образце «Ботвиново» меняются в LineCapacity и в VoltPlan,
  файлы совпадают;
- каждый файл, построенный в LineCapacity, VoltPlan читает и записывает
  байт-в-байт;
- две схемы, построенные в VoltPlan, открываются в LineCapacity, рисуются
  (снимок окна) и пересохраняются без изменений;
- все 18 образцов пересохраняются в LineCapacity и в VoltPlan одинаково.

Сравнение файлов построчное. Приравнивается только высота шины ТП: в новой
схеме LineCapacity берёт её из размера окна (см. «Построение схемы»).

## Дефекты, найденные при тестировании и исправленные

| Что было | Как найдено | Исправление |
|---|---|---|
| правка любой ЛЭП, кроме ответвления к потребителю, делала её трёхфазной | правка надписи в образце в обеих программах | фазность меняется только по выбору пользователя, выбор есть у любой ЛЭП |
| панель свойств округляла числа до 6 знаков и отправляла все поля | то же | числа показываются полностью, отправляются только изменённые поля |
| отмена убирала всё действие целиком | сценарий в обеих программах | состояние запоминается после каждого добавления ЛЭП, опоры и потребителя, как в LineCapacity |
| значения по умолчанию в окнах отличались | окна, принятые без изменений, в обеих программах | заполнение окон по правилам LineCapacity на сервере |
| сервер принимал надписи с переводом строки, символы вне Windows-1251, огромные числа | запросы к API | проверка входных данных, пределы массивов LineCapacity, русские сообщения |
| после удаления потребителя окно нового заполнялось значениями по умолчанию, а в LineCapacity — удалённого | сценарий «удаление» | резерв удалённых объектов, как в LineCapacity |
| отмена отходящей ЛЭП занижала счётчик отходящих линий | сценарии отмены в обеих программах | состояние запоминается после увеличения счётчика |
| сообщение об ошибке перекрывало кнопки или шапку окна | снимки экрана | сообщение наверху и скрывается при открытии окна |

## Материалы

- `журналы/`:
  - вывод трёх прогонов pytest;
  - отчёт о покрытии;
  - журнал сервера за прогоны.
- `запросы/` — 13 запросов к API: файл `.http` и настоящий ответ сервера в
  `.json` рядом. Среди них:
  - справочник;
  - окна;
  - новая схема;
  - меню точки;
  - ответвление;
  - отказ;
  - правка;
  - отмена;
  - ошибка ввода;
  - сохранение и открытие `.cir`.

  В ответах справочника и открытия файла списки сокращены до трёх элементов.
- `скриншоты/`:
  - `интерфейс-*` — снимки VoltPlan из проверок в браузере;
  - `linecapacity-*` — окна LineCapacity со схемами, построенными теми же
    действиями, и с открытыми файлами VoltPlan.
- `файлы-cir/` — файлы сверки:
  - `*-linecapacity.cir` — файл, сохранённый LineCapacity после сценария;
  - `*-voltplan.cir` — файл VoltPlan после тех же действий;
  - `*-из-voltplan.cir` и `*-пересохранено.cir` — наш файл до и после
    пересохранения в LineCapacity;
  - `образец-*.cir` — образцы, пересохранённые LineCapacity;
  - `правка-образца-*.cir` — «Ботвиново» после правки надписей в каждой из
    программ.
- `План-этапа-2.md` — уточнённый план следующего этапа.

## Как повторить

```
pip install -e .[test]
python -m pytest
python -m pytest tests/live -m live
set LINECAPACITY_EXE=C:\путь\LineCapacity.exe
python -m pytest tests/linecapacity -m linecapacity
```

Проверки в LineCapacity управляют окнами и мышью, поэтому во время прогона
компьютером пользоваться нельзя.
