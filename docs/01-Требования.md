# Требования и их трассировка

Источник требований — три задания на курсовой проект (папка `Задания`) и
договорённости команды. Каждое требование получило код; в таблицах указано,
на каком этапе оно выполняется и чем проверяется.

Обозначения источников: **Д** — задание Дешева А. П., **Р** — задание
Рылушкина Б. А., **С** — задание Стасева Б. В., **К** — договорённость команды.

## Темы заданий

| Задание | Тема |
|---|---|
| Д | Программный продукт для сравнения нескольких вариантов электрической схемы по итогам моделирования и оплаты доступа к системе |
| Р | Программный продукт для построения модели электрической сети на холсте и моделирования её режима при разных сезонных нагрузках |
| С | Программный продукт для моделирования режимов электрической сети по нескольким сценариям и обмена схемами во внешнем формате |
